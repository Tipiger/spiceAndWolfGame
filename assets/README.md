# 图片目录与发布范围

`source/` 保存制作源，`runtime/` 保存游戏实际加载和网站发布的图片。两类文件分目录维护，游戏不得引用 `source/`。整套原作资料库保留原位。

| 目录 | 内容 | 数量与尺寸 | 网站发布 |
| --- | --- | --- | --- |
| `source/novel/hd/` | 小说插图高清增强母版，含四幅中文彩页；无损 PNG | 13幅，宽1038–2926像素，约40.23 MiB | 否 |
| `source/novel/input/` | 高清增强前的去水印修复输入及用户选定合图；PNG | 12张400像素扫描修复图＋1幅1463×1075初遇合图，约5.00 MiB | 否 |
| `source/official/` | 官网原始 JPEG，保持原分辨率；包括保留但当前未使用的月夜立绘 | 4张，375–1488像素宽 | 否 |
| `source/map/` | 地图与城镇制作母版；PNG | 4张，1052–1254像素宽 | 否 |
| `source/events/` | 暴雨、丰收、节庆、酒馆、旅人场景母版；PNG | 5张，1536×1024 | 否 |
| `source/story/` | 主线亚麻纹样母版；PNG | 1张，1536×1024 | 否 |
| `source/wagon/` | 已验收的两帧透明马车制作源；PNG | 2张，各512×341 | 否 |
| `runtime/` | 按用途分组的最终发布图：`novel/`、`official/`、`map/`、`events/`、`story/`、`wagon/`，以及麦穗标记 | 28张质量92 WebP与1张 SVG，共约11.68 MiB | 是，全部使用 |
| `狼与香辛料原作/` | 用户提供的小说正文、原始扫描及书源标记 | 保持原样 | 否，也不进入离线发行包 |

小说高清母版由AI增强与局部翻译得到，包含推补细节，并非官方高清扫描。未经增强的输入和带书源标记的原扫描分别保留在上表对应目录，不能互相覆盖。考据、译文和实际提示词见 [小说插图记录](../docs/novel-art.md) 与 [图片来源](../docs/assets-sources.md)。

`scripts/image-exports.json` 逐张记录制作源、发布图、编码选项与文件摘要；SVG 不转码。修改母版后运行 `npm run images`，再运行 `npm run verify`。重新导出需要维护者本机安装 `cwebp`，普通校验、构建和游玩无需安装。

`_site/` 是网站发布结果，只包含 `runtime/` 中的图片；可编辑离线 ZIP 同时包含42份制作源、29份发布图和本说明。两种发布结果均排除原作库、本地候选预览和临时对照图。不要把制作源复制进 `runtime/`，也不要另留中间质量档。
